# World Event Timers

Countdowns for Sinkholes, Big Chinchompa, the Prifddinas raven, daily/weekly/monthly resets and up to 8 custom timers, plus this week's rotations. Optional alarms with repeat and volume settings.

Current version: 0.12.11

- Install from mod.io: https://mod.io/g/runescape/m/world-event-timers

## Report a bug or request a feature

Open an issue: https://github.com/MAX-Q00/world-event-timers/issues/new/choose
